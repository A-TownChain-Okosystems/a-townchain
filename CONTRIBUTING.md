# Contributing to atc-vm

## Beitragsregeln (A-TownChain Governance)

Beiträge zur A-TownChain Virtual Machine (`atc-vm`) folgen den A-TownChain Governance-Standards (ATC-STD-000, ATC-STD-201, ATC-STD-MD-001).

### Workflow
1. **Issue / Task:** Aufgabe im Entwicklungsplan identifizieren.
2. **Rust-first:** Kanonische Implementierung erfolgt in Rust (AD-021).
3. **Commits:** Conventional Commits verwenden (`feat`, `fix`, `docs`, `security`, `chore`).
4. **Validation:** Lokale Tests (`cargo test`) und Fuzzing ausführen.
5. **Pull Request:** PR erstellen und CI-Pass abwarten.
