# Genesis Engine Documentation

Canonical documentation index for the monolithic Genesis Engine workspace.

## Sections

- `architecture/` — subsystem boundaries and dependency rules
- `getting-started/` — installation, first project and first scene
- `runtime/` — lifecycle, ECS, simulation and determinism
- `rendering/` — renderer abstraction and frame lifecycle
- `world/` — terrain, biomes, weather and streaming
- `gameplay/` — animation, physics, AI and input
- `networking/` — replication and authority model
- `tools/` — editor, profiler, CLI and build pipeline
- `sdk/` — stable game-facing API
- `governance/` — standards, evidence and release gates

The repository root remains the source of truth until individual subsystems are intentionally promoted to standalone repositories.
