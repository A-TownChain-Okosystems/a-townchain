# Genesis Project Templates

Starter layouts for 2D, 3D, multiplayer and simulation projects. Templates are intentionally data-first and contain no game-specific IP.

## Profiles

- `minimal-2d` — smallest runnable project
- `standard-3d` — world, camera, input and asset pipeline
- `multiplayer` — authority/prediction/interpolation skeleton
- `simulation` — deterministic fixed-timestep simulation
