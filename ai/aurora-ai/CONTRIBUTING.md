# Contributing to Aurora AI

> Richtlinien für Beiträge zum Repository `aurora-ai`.

## Beitragsregeln

1. **Standards-Konformität:** Alle Änderungen müssen den Standards `ATC-STD-000`, `ATC-STD-201`, `ATC-STD-README-001` und `ATC-STD-MD-001` entsprechen.
2. **Commit-Format:** Verwenden Sie Conventional Commits mit dem vorgeschriebenen Agenten-Trailer-Block bei automatisierten Commits.
3. **Testing:** Stellen Sie sicher, dass alle Tests (`cargo test`, `pytest`) vor dem Erstellen eines Pull Requests erfolgreich durchlaufen.
4. **Dokumentation:** Aktualisieren Sie `CHANGELOG.md` und gegebenenfalls `ARCHITECTURE.md` oder `STATUS.md`.
