# Code of Conduct

## Verhalten

Wir arbeiten respektvoll, professionell und transparent zusammen. Kritik
gilt der Sache, nie der Person.

## Regeln

- Keine persönlichen Angriffe, Belästigung oder Diskriminierung
- Keine Veröffentlichung von Schwachstellen (siehe SECURITY.md, ATC-STD-203)
- Keine Secrets, Tokens oder Zugangsdaten in Dokumenten oder Issues
- Agenten-Beiträge sind gekennzeichnet (AI-DEV-007) und AUD-pflichtig

## Meldewege

Verstöße werden über den offiziellen ATC-Security-Reporting-Prozess
gemeldet (SECURITY.md) oder direkt an die Repository-Maintainer
(A-TownChain-Okosystems).
