## 1. Ist-Zustand (Evidence)

atclang ist seit Welle 2 (17.09., Commit e915589) ein end-to-end Compiler:
Lexer → Parser → kanonische AST-JSON (bytgleich zum eingefrorenen Korpus, SCR-0084/0085) →
Bytecode-Lowering mit Verifizierer-Zwang (`src/lower.rs`) → deterministische i64-Stack-Maschine
(`src/vm.rs`: checked-Arithmetik, Div/0 statisch+dynamisch fail-closed, Aufruftiefe 1024).
CLI: `atc compile|run|check`. 25 Tests, fmt/clippy clean, 7/7 CI-Gates grün.

**Fehlt für Sprachreife:** Kontrollstrukturen (if/else, while), Vergleiche/Booleans,
und die Bindung an die ATC-VM des L1-Monorepos (bisher läuft die Ausführung auf der
atclang-eigenen Referenz-VM).

## 2. Lösung (drei Stufen, je mit Evidence-Gate)

### Stufe 1 — Sprachumfang (atclang, autonom)

- **Parser/AST:** `if <expr> { ... } else { ... }`, `while <expr> { ... }`,
  Vergleichsoperatoren `== != < > <= >=` (Booleans als i64 0/1 kodiert, deterministisch).
- **Bytecode:** neue Instruktionen `JumpIfFalse(target)` und `Jump(target)`
  (PC-relativ, u16-Distanz). Rückwärts-Sprünge nur aus `while`-Lowering mit
  dokumentierter Schleifen-Semantik.
- **Verifizierer:** Sprungziel-Validierung (Ziel in [0, len], Ziel = Instruktionsgrenze,
  Stack-Höhe am Ziel ≥ Höhe vor dem bedingten Sprung); kein unvalidierter Pfad.
- **VM:** PC-Sprünge im Frame; keine neuen Host-Kontakte (Determinism-Gate bleibt grün).
- **Differential:** Korpus nur ERWEITERN (neue `*.atc` + `expected/*.json`); bestehende
  Einträge byte-stabil. Neue End-to-End-Tests: Fakultät via while, bedingte Pfade,
  Short-Circuit-freie Vergleichsketten.

### Stufe 2 — ATC-VM-ABI-Bindung (a-townchain/components/vm, nach Stufe-1-Freigabe)

- **Schema-Abgleich:** atclang-Bytecode-Instruktionsset als ABI-Dokument
  (`docs/abi.md` in atclang); ATC-VM erhält einen atclang-Bytecode-Loader oder
  eine Übersetzungstabelle (atclang-Instr → ATC-VM-Instr).
- **Golden Vectors:** gemeinsame Vektor-Datei (Programm → erwartetes i64-Ergebnis),
  die BOTH VMs deterministic durchlaufen müssen (Kreuz-VM-Differential).
- **Scope-Grenze:** keine Änderung an ATC-VM-Konsens-/Gas-Semantik; nur Lade-/Decode-Pfad.

### Stufe 3 — Freigabe & Registry

- Erfolgreiche Stufen 1+2 werden als Maintenance-Record (ATC-STD-MAINT-019, YAML)
  in atclang `.atc/evidence/` gebunden; Umbrella-Sync via subtree pull.
- ATC-STD-620..627 (ATCLang-Standards) bleiben blockiert (AD-023); dieser SCR ist
  bewusst KEIN Standard-Antrag — Sprachreife wird über CI-Evidence belegt.
