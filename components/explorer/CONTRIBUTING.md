# Contributing

Dieses Repository steht unter der ATC-Governance der A-TownChain-Okosystems-Organisation.

- **Standards (SSOT):** Verbindlich sind die Eintraege in [atc-standards/registry/standards.yaml](https://github.com/A-TownChain-Okosystems/atc-standards/blob/main/registry/standards.yaml) — ATC-STD-003 (Governance Determinism) regelt die Ein-Zahl-Regel.
- **Aenderungen:** via SCR (Change Request) mit Evidence-Bindung (.atc/evidence/evidence.yaml). Claims ohne maschinenpruefbaren Nachweis werden abgelehnt (No-Evidence-No-Claim, ATC-STD-018).
- **Lizenz:** Apache-2.0 (Copyright Michael Wroblewski). Beim Beitrag wird die Lizenz akzeptiert.
- **KI-Agenten:** sind Executor/Auditor/Maintainer — niemals Approver (ATC-STD-003 par.9). Agenten-Aenderungen tragen den [agent: ...]-Commit-Trailer und laufen gegen die Governance-CI.
- **Sicherheit:** Keine Sicherheitsprobleme in oeffentlichen Issues melden — Private Vulnerability Reporting verwenden (siehe SECURITY.md).
