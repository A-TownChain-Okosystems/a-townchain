# Governance — ATC Algorithm

Dieses Repository unterliegt dem **A-TownChain Enterprise Governance Framework (ATC-STD-000)**.

## Entscheidungsregeln & Review-Pflichten

- **Sicherheits- & Konsens-Kritikalität:** Konsens-Code ist S4-kritisch. Änderungen an Konsens-Regeln, PoH-Tick-Frequenzen, Hybrid-Gewichtungen oder kryptografischen Primitiven erfordern formale Review und §9-Owner-Freigabe.
- **Change Requests (SCR):** Änderungen an APPROVED-Standards oder Kernschnittstellen erfolgen ausschließlich über Specification Change Requests (SCR).
- **Immutabilität:** Nach Freigabe gelten die Immutabilitätsregeln nach ATC-STD-000 §30.
