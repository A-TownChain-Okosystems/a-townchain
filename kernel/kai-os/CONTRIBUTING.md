# Contributing to a-townchain-os

## Beitragsregeln (A-TownChain Governance)

Beiträge zum Repository `a-townchain-os` folgen den A-TownChain Governance-Standards (ATC-STD-000, ATC-STD-201, ATC-STD-MD-001).

### Workflow
1. **Issue / Task:** Aufgabe im Entwicklungsplan identifizieren.
2. **Architecture & Standards:** Änderungen an Modulen erfolgen primär im jeweiligen Produkt-Repository (AD-017: Produkt gewinnt).
3. **Commits:** Conventional Commits verwenden (`feat`, `fix`, `docs`, `security`, `chore`).
4. **Validation:** Lokale Tests (`cargo test --workspace`) und Governance-Checks ausführen.
5. **Pull Request:** PR erstellen und CI-Pass abwarten.
