# Code of Conduct — A-TownChain Ökosystem

## Grundsätze

Alle Mitwirkenden verpflichten sich zu respektvoller, fachlich fundierter und konstruktiver Zusammenarbeit im A-TownChain-Ökosystem. Einhaltung der Governance-Richtlinien (ATC-STD-000) ist verbindlich.
