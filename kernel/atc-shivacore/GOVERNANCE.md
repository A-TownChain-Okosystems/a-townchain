# Governance — atc-shivacore

## Governance Framework

This repository is governed according to **ATC-STD-000** (A-TownChain Enterprise Governance Framework).

- **Architectural & Consensus Changes:** Require an approved System Change Request (SCR) per ATC-STD-000 §19-33.
- **Review & Approval:** Changes to microkernel code or core protocols require review and §9 Owner sign-off.
- **Security Compliance:** Security class S4 / Criticality C1. All security policies in `SECURITY.md` apply.
