# 💻 Befehlsübersicht — atc-cli

---

## 1. Node Befehle (`atc-cli node`)

| Befehl | Beschreibung |
|--------|--------------|
| `atc-cli node start` | Startet den lokales Node-Dienst |
| `atc-cli node status` | Zeigt Sync-Status und Peer-Anzahl |

## 2. Wallet Befehle (`atc-cli wallet`)

| Befehl | Beschreibung |
|--------|--------------|
| `atc-cli wallet create` | Erstellt ein neues Wallet mit Mnemonic |
| `atc-cli wallet balance` | Fragt Kontostände ab |
| `atc-cli wallet send` | Sendet Transaktionen |

## 3. Contract Befehle (`atc-cli contract`)

| Befehl | Beschreibung |
|--------|--------------|
| `atc-cli contract deploy` | Kompiliert und deployt ATCLang Contracts |
| `atc-cli contract call` | Ruft Vertragskennzahlen ab |
