# 🔒 Sicherheit — atc-wallet

## Sicherheits-Prinzipien

1. **Zero-Plaintext Storage**: Private Keys werden ausschließlich im Speicher temporär entschlüsselt.
2. **Offline / Air-Gapped Mode**: Moeglichkeit der Offline-Signierung über QR-Code payloads.
3. **Multi-Signature Governance**: Schwellenwert-Signaturen für Organisations-Accounts.
