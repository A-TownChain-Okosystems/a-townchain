# 🛠️ LSP Spezifikation — atc-ide

Der ATCLang Language Server implementiert die Sprachunterstützung für `.atc` Dateien.

## Funktionen

- **Completion**: Keywords, Funktionen und Smart Contract Methods.
- **Diagnostics**: Syntaxfehler, Type Checking und Security Warnings.
- **Hover**: Funktionssignaturen und Dokumentations-Tooltips.
- **Definition**: Navigation zu Typdefinitionen und Symbolen.
