# 🏗️ Architektur — atc-mobile

Die Mobile App kombiniert eine React Native Oberfläche mit nativen Modulen für kryptographische Operationen.

## Komponenten

- **Mobile Viewport UI**: Optimierte Responsive Views für Smartphones und Tablets.
- **Biometric Enclave Integration**: Nutzt Keychain (iOS) und Keystore (Android) zur sicheren Aufbewahrung.
- **`wallet_api.atc`**: Anbindung an Gateway-Dienste.
