# 🧩 Komponenten — atc-frontend

## Core UI Components

1. **`index.html`**: Hauptoberflaeche mit Neon Dark-Theme, Desktop Navigation, System Monitor und Quick Launch Bar.
2. **`bootscreen/`**: Boot-Sequenz Emulator zur Darstellung von Systemstarts, Modulladevorgaengen und Hardware-Checks.
3. **`battle/`**: Web3 Game Canvas für Shivamon Arena Matches und NFT Stat Display.
4. **`assets/js/api.js`**: Universal Client zur Anbindung aller Backend-Endpunkte.
