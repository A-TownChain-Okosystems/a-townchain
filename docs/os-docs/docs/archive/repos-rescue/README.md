# Repos-Rescue — Originale der gelöschten Alt-Repos

> Angelegt 06.09.2026 im Zuge der Löschung der 124 archivierten Alt-Repos.

Dieser Ordner sichert die **pristinen Original-Stände** aller archivierten
Repos, die am 06.09.2026 aufgelöst wurden:

- **Dateien hier:** 527 Dateien, deren Inhalt sich vom Stand in Monorepo/Hub
  unterscheidet (evtl. nur durch nachträgliche Copyright-Header oder Link-
  Fixes). Alle übrigen Dateien der Alt-Repos sind byte-identisch in
  `a-townchain-os` (src/modules/, Stand K-Migration) bzw. hier im Hub
  (docs/archive/wiki/, docs/monorepo-legacy/) vorhanden — verifiziert per
  SHA-256 über alle 2.966 Dateien der 124 Repos.
- **`_ISSUES_DUMP.json`:** alle 9 Issues des alten atc-genesis-engine-Repos
  (als einziges Archiv-Repo mit Issues; als PR-gefilterte JSON-Liste).

Die Git-Historie der gelöschten Repos (Commits abseits des finalen Stands)
ist mit den Repos gelöscht; der finale Datei-Stand ist vollständig erhalten.
