Das Repository `atc-globus-shell` bietet die Shell-Schnittstelle von GlobusOS. Es umfasst Terminal-Emulation, Befehlszeilen-Parsing und die zentrale Command-Processor-Engine zur interaktiven Ausführung von Betriebssystem- und System-Befehlen.

## Komponenten

- `src/shell.atc` — GlobusOS Shell Controller & Terminal Loop
- `src/cli.atc` — Command Line Interface Parser & Argument Handling
