# Security Policy — demo-repository

> **Ehrliche Einordnung:** Dieses Repo ist das GitHub-Template-Repo der Organisation (EXPERIMENTAL,
> Registry `ATC-REPO-DEMO-001`). Es enthält KEINEN Produktionscode und keine Geheimnisse.

## Meldung von Sicherheitsproblemen

Sicherheitsprobleme der A-TownChain-Organisation werden **nicht** hier gemeldet, sondern
zentral über das SECURITY.md des jeweiligen Produkt-Repositories oder an den Security-Owner
(@ShivaCoreDev). Siehe auch: `atc-standards` (Security-Standards) und AUD-2026-0005.

## Geltungsbereich

Nur dieses Template-Repo (index.html, Template-Workflows). Ketten-/OS-/AI-Komponenten der
Organisation haben eigene Security-Policies in ihren Repos.

## Regeln

- Keine Secrets in Template-Workflows (fail-closed).
- Änderungen nur via PR (ATC-STD-000 §7.5).
