# Contributing — demo-repository

> **Ehrlich:** Dieses Repo ist die GitHub-Template-Demo der Organisation. Es ist bewusst
> minimal gehalten. Produktive Arbeit gehört in die Fach-Repos (Landkarte: AD-024).

## Regeln (verbindlich für alle Repos der Organisation)

1. **Vor jeder Änderung lesen** (Governance im Wiki-Repo `a-townchain-os-docs`):
   AGENT_POLICY.md, AGENT_COORDINATION.md, DECISIONS_REGISTER.md.
2. **Nur via PR** — direkte Pushes auf `main` sind gesperrt (ATC-STD-000 §7.5).
3. **Ehrlichkeit vor Status:** CLAIMED ≠ PASS · DOCUMENTED ≠ IMPLEMENTED (SCR-0080).
4. **Sprache:** Deutsch in Dokumentation/Issues; Code-Bezeichner Englisch.

## Für dieses Repo

- Kein Produktionscode hier — Änderungen nur an Template/Struktur.
- Jede Änderung muss die `.atc/`-Metadaten konsistent halten.
