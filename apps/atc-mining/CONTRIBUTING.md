# Contributing to atc-mining

Vielen Dank für Ihr Interesse an Beiträgen zu `atc-mining` im A-TownChain-Ökosystem.

## Entwicklungsrichtlinien

1. **Governance & Standards**: Alle Beiträge müssen den Standards ATC-STD-000, ATC-STD-201 und ATC-STD-SC-018 entsprechen.
2. **Code Quality**: Rust-Code muss mit `cargo fmt` und `cargo clippy` geprüft werden.
3. **Tests**: Jeder neue Code erfordert entsprechende Unit- oder Integrationstests (`cargo test`).
4. **Commits**: Verwenden Sie Conventional Commits (z. B. `feat:`, `fix:`, `docs:`) und fügen Sie Agenten-Trailer hinzu.
5. **Pull Requests**: Reichen Sie Pull Requests gegen den `main`-Branch ein.
