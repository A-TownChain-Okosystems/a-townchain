# Threat-Modell — atc-engineering

Assets: Org-Metadaten, CI-Ergebnisse, Policies, Evidence-Bundles.
Keine Secrets/Keys/Chain-Assets im Scope (S2/C2).

Hauptbedrohungen: Policy-Bypass (fail-closed dagegen), falsche
Status-Derivation (Evidence-Verifikation dagegen), Token-Missbrauch
(minimaler Scope, read-mostly), Generierte-Workflow-Manipulation
(reproduzierbar + Owner-Review).
